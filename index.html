DC Fast-Charging Station — Link Firmware

NDA · code not public

STM32H723 · CAN 2.0B ring network · MISRA C:2012

A multi-gun DC charging network wired as a closed ring. When one EV demands more power than a single power module can deliver, the firmware autonomously borrows capacity from idle guns and reclaims it when the vehicle finishes or a new one arrives.

  • 4-layer architecture — App → Middleware (Service / FSM / Control) → Driver → HAL, with upward-only calls enforced. Drivers hold no state machines and know nothing about the protocol above them.
  • SPI-to-CAN driver stack — MCP2515 bit timing for 125 kbit/s, ISR-level frame buffering, bus-off self-recovery.
  • CAN frame codec — 29-bit identifier packed from six named fields with explicit shift/mask definitions, and range validation on every field.
  • Distributed power algorithms — ring traversal by modulo, two-direction idle-gun discovery, event-priority reclamation, and safe contactor sequencing that ramps current to zero before opening a contactor.
  • Station state machine — INIT → DISCOVERY → RUN → SAFE, fully non-blocking, zero HAL_Delay().
  • Single-writer ownership — each shared variable has exactly one writing task, eliminating data races by construction.
  • Quality pipeline — cppcheck + MISRA addon, unit tests on PC with a mocked HAL, fault injection (stuck contactor, unplugged CAN, current sensor failure), logic-analyser bench verification, 24-hour soak test.
